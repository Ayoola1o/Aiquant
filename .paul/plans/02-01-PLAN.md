<objective>
## Goal
Optimize core quantitative performance bottlenecks in `backtest_engine.py` and `feature_engine/engine.py`.

## Purpose
Row-by-row candle iteration in `backtest_engine.py` currently executes `np.vstack` on every candle iteration, causing $O(N^2)$ array re-allocations and severe slowdowns on large historical datasets (10,000+ candles). Replacing this with pre-allocated NumPy array view slicing reduces backtest execution time by up to 90%. Additionally, feature engine module calculations can avoid unnecessary DataFrame copying.

## Output
- High-performance vector-preallocated array slicing in `backtest_engine.py`
- Optimized pipeline execution in `backend/feature_engine/engine.py`
- Verified unit performance and execution accuracy
</objective>
