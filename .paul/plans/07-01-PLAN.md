<objective>
## Goal
Add per-bot date-categorized Daily PnL tracking (`daily_pnl_by_date`) to `TradingBot` in `backend/trading_engine.py`, expose daily PnL history via bot state API in `backend/main.py`, and render interactive Daily PnL Date Breakdown cards/tables in `frontend/src/components/LiveSession.tsx` and `AIStrategyLab.tsx`.

## Purpose
Enables quantitative traders and bot operators to distinguish performance across different calendar days, tracking daily realized profits/losses, daily trade counts, and daily win rates per active trading bot.

## Output
- `TradingBot.daily_pnl_by_date` tracking in `backend/trading_engine.py`
- Exposed `daily_pnl_list` in bot state API (`backend/main.py`)
- Daily PnL Breakdown UI component in `LiveSession.tsx` & `AIStrategyLab.tsx`
</objective>
