## Goal
Implement real-time execution risk telemetry, drawdown monitoring, and live risk metrics API integration across backend engines and the frontend Risk Command Center UI.

## Purpose
Provides quantitative traders with real-time risk supervision, circuit breakers (max drawdown, price collar limits, order caps), and live telemetry streaming to prevent unexpected execution losses during active trading sessions.

## Output
- Enhanced `RiskManager` circuit breaker and validation in `backend/trading_engine.py`
- Exposed `/api/risk/status` telemetry endpoint in `backend/main.py`
- Real-time risk status integration in `RiskCommandCenter.tsx`
</objective>
